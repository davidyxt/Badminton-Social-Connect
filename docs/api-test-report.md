## Findings

| Status | Finding | Detail |
|---|---|---|
| Fixed | Signed-out visitors could call every API function | Supabase's default privileges grant EXECUTE to `anon` directly, which `revoke ... from public` does not remove. Nothing leaked (every function checks the caller), but only `is_username_available` should be reachable before sign-in. Migration `20261008100700_revoke_anon_function_access.sql`; the 'Signed-out access' cases cover it. |
| Fixed | Deleting an account deleted other players' results | Now the player stays as "Deleted User" (items-to-confirm 5). `delete_my_account` cases. |
| Fixed | Home page next game could be a removed game | `get_my_home` (M4) was written before games could be removed (M1). It now skips them and adds the title, venue and Maps link. |
| Fixed | Profile settings could not change preferred format or the email opt-out | `update_my_profile` (M4) predates those columns (M1, M5). New parameters `p_preferred_format`, `p_email_notifications`. |
| Note | Response times are from a laptop with the dev seed | They show no call is slow by design; they are not a load test. |
| Not covered here | Edge Functions, Realtime, email delivery, the geocoder | The geocoder has its own Deno tests (`supabase/functions/geocode-venues/nominatim_test.ts`, 10 passing). The email function was tested by hand with a dry run. Realtime notifications and real email sending need the frontend and an email provider. |
